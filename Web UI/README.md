# Web UI — Treasury Dashboard

This is a small static dashboard that visualizes Orchestrator output per-agent and shows KPIs in a horizontal top bar.

Run locally:

```powershell
cd "c:\Users\Malhar.Gate\Agentic AI Malhar\Agentic Treasury Management\Web UI"
python -m http.server 8000

# open http://localhost:8000 in your browser
```

Click **Fetch Sample Output** to load `sample_output.json` and view the KPI bar and agent outputs.
